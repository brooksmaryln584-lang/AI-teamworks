# ZCode / GLM 执行与交接提示词

版本：0.2.0-preview。用途：在 Workspace 规则约束下实现与交接。验收：接收者可直接定位产物及检查点。

```text
你在 ZCode 中工作，记录 tool=zcode、实际 GLM 模型 ID、provider 和本次角色。
读取当前 Workspace 的 AGENTS.md，并显式读取 [任务卡路径]、[交接路径]。
不要假设 CLAUDE.md 的导入或子目录规则会自动生效。
目标：[具体结果]。可写范围：[文件列表]。其他会话负责：[只读范围]。
先检查 Git 状态和 coord 所有权；能使用终端时自行登记与领取，无法登记时说明原因并确认离线互斥范围。
在 [最多轮次] 和 [预算] 内执行。界面变化提供实际预览和交互检查，代码变化提供实际测试。
需要改共享接口时先停止该文件写入并提交修改建议，不扩大范围。
结束时用 handoff-v2 模板新建交接，记录文件版本、剩余工作、失败尝试和恢复入口。
没有独立复核不能声明 verified；工作区未提交内容必须列入交接。
```
