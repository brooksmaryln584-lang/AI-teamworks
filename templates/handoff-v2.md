# 交接：填写任务名称

版本：0.2.0-preview。用途：跨客户端恢复与独立复核。验收：接收者凭本文件和仓库即可核对下一步。

- task_id / source_agent_id / target_agent_id：
- tool / model / provider / role：
- session_id / run_id / 观察时间：
- 当前状态（working/submitted/verified/closed，写依据）：
- 项目 / 分支 / 提交或文件 SHA-256：
- 原任务 claim 状态 / lease_until：
- 接收方可写范围 / 其他会话持有范围：

## 目标与证据

- 用户目标及验收标准：
- 本次实际修改的文件：
- 实际检查命令、退出码、时间和结果：
- 没有运行的检查及原因：
- 执行者 receipt 路径与 SHA-256：
- 独立复核报告（未完成则写未完成）：

## 从这里继续

- 已确定的约束：
- 未完成项和阻塞：
- 已失败的尝试及证据：
- 下一条具体动作：
- 恢复前必须重新核对的事实：
- 已用轮次 / 总轮次 / 剩余预算：
- 停止条件：

接收者先只读检查；范围归属确认且领取成功后才能继续修改。报告中不得放入凭据、认证响应或原始私人聊天。
