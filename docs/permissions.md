# 权限与配置所有权

版本：0.1.0-draft。用途：从私有中枢提炼可复用授权边界。验收：每项操作能对应任务范围、配置所有者及验证方式。

| 等级 | 操作 | 本流程要求 |
| --- | --- | --- |
| L0 | 读取文件、版本、哈希 | 按任务目的读取必要信息 |
| L1 | 修改指定工作区文件 | 任务授权明确范围 |
| L2a | 本地测试、构建、服务 | 任务覆盖对应执行类型 |
| L2b | 外部网络、模型或 API | 明确域名、操作、预算或副作用上限 |
| L3 | 安装、用户配置、provider、PATH、插件 | 明确授权具体变更，保留恢复办法 |
| L4 | 公开发布、重要数据删除、生产或账号权限写入 | 执行前确认准确目标和可审阅内容 |

这是团队工作约定，不能替代运行器沙箱、操作系统权限和平台授权。用户已有授权继续有效；出现范围变化或新风险才重新确认。

用户决定任务目标和 provider；安装器负责二进制；provider 管理器负责配置数据库与生成配置；执行者负责已领取的项目文件；中枢负责规则、模板与证据记录。不要让多方无版本记录地覆盖同一配置。

配置变更前记录非秘密版本或哈希和恢复位置，变更后检查实际生效入口。记录预算不等于技术强制限额。恢复方案也不得把密钥复制到仓库。
