# Ollama 可选接入

版本：0.1.0-draft。用途：为适合本地模型的任务增加独立运行入口。验收：确认 CLI、模型清单及一次受控的本地推理；本次文档准备没有下载模型或运行推理。

从 [ollama/ollama](https://github.com/ollama/ollama) 的 README 与 Releases 选择对应系统安装方式。先记录版本和已有模型：

```powershell
ollama --version
ollama list
```

需要新模型时，先根据内存、磁盘、模型许可和任务选择具体标签，再按上游说明下载和运行。不要把未验证的模型名固定成所有用户的默认选项。

适合先尝试的工作：整理已经脱敏的项目说明、生成待人工核对的草稿、对固定样例做重复评测。测试效果后再决定是否参与正式流程。本地运行也需要核对实际调用路径、插件和网络行为，不能仅凭安装了 Ollama 就断言所有数据不出本机。

Ollama 在此作为独立工具入口；本包不宣称 Codex、Claude Code 都能无配置地切换到同一个本地模型，也没有附带未经验证的 provider 配置。它产生的产物仍遵守任务范围、证据和复核规则。
